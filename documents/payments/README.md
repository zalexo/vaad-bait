# Подтверждения оплат жильцов

Здесь хранятся подтверждения оплат жильцов за домовой комитет
(`מס ועד בית`), целевые сборы и связанные переводы от квартир.

Файлы именуются:

`YYYY-MM-DD-apartment-N-краткое-описание.ext`

Пример:

`2026-07-01-apartment-15-vaad-fee.pdf`

Связанный путь указывается в `finance/payments.xlsx`.
