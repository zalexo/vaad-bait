# PDF-отчёты по расходам

Здесь хранятся PDF-отчёты, предназначенные для отправки жильцам. Эталон
оформления — утверждённый локальный файл `expenses-2026-06-he.pdf`; каждый
новый отчёт должен сохранять ту же одностраничную структуру и стиль.

## Обязательный порядок работы агента

1. Прочитать этот файл и данные нужного месяца из
   `finance/expenses/YYYY-MM.md`.
2. Взять только строки со статусом `подтверждено`; проверить количество
   операций и сумму.
3. Создать файл через `scripts/generate_expense_report.swift` с именем
   `expenses-YYYY-MM-he.pdf`.
4. Открыть получившийся PDF и визуально сверить его с
   `expenses-2026-06-he.pdf`: A4 landscape, RTL, карточки, таблица, без
   обрезанного или съехавшего текста.
5. Только после такой проверки отправлять PDF жильцам.

## Обязательный формат

- PDF формата A4, одна страница, **горизонтальная ориентация**, направление
  текста справа налево (`RTL`), весь текст на иврите.
- Шапка: маленькая надпись `ועד הבית`, крупный заголовок
  `דו״ח הוצאות לחודש <месяц год>` и подзаголовок
  `סיכום הוצאות מאושרות לפי רישומי ועד הבית`.
- Тонкая зелёная разделительная линия вверху.
- Три одинаковые светлые карточки: `מספר פעולות`, `הוצאות מאושרות`,
  `סה״כ הוצאות`.
- Одна таблица с тёмно-зелёной шапкой и колонками (справа налево):
  `#` | `תאריך` | `קטגוריה` | `ספק` | `תיאור` | `קבלה` | `סטטוס` | `סכום`.
  Для статуса `מאושר` использовать светло-зелёную плашку; наличие документа
  указывать как `קיימת`.
- Под таблицей — пояснение: `כל הסכומים מוצגים בשקלים חדשים. הקבלות שמורות
  אצל ועד הבית לצורכי מעקב ובקרה.` Внизу — дата создания отчёта.
- Включать только операции со статусом `подтверждено` из
  `finance/expenses/YYYY-MM.md`. Если операций несколько, каждая занимает
  отдельную строку, итог — сумма всех таких операций.

Имя файла: `expenses-YYYY-MM-he.pdf`.

Генератор: `scripts/generate_expense_report.swift`. Он работает локально и
создаёт PDF по этому шаблону; перед отправкой проверять итог и визуальное
оформление.
