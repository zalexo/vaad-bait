# Карточки квартир

В этой папке лежит маленькая платёжная карточка по каждой квартире.

Файлы:

- `apartment-01.md` ... `apartment-20.md`

Карточка квартиры хранит историю платежей и заметки по конкретной
квартире. Общая сводка по всем квартирам остаётся в
`finance/payments.xlsx`.

## Правило синхронизации

При каждом новом платеже или исправлении нужно обновить:

1. карточку конкретной квартиры;
2. `finance/payments.xlsx`.

После этого сверить:

- период;
- начисленную сумму;
- оплаченную сумму;
- долг или переплату;
- дату оплаты;
- статус;
- путь к документу.
