# Расходы домового комитета

Расходы ведутся в Markdown по месяцам:

- `2026-06.md`
- `2026-07.md`
- `2026-08.md`

Такой файл — единственный источник истины по расходам соответствующего
месяца. Каждая операция занимает одну строку таблицы. Не удаляйте старые
операции: исправление вносится новой строкой с понятной пометкой.

## Формат записи

Для каждой операции указывать:

- дату операции в формате `YYYY-MM-DD`;
- категорию и поставщика;
- назначение на русском и короткое описание на иврите;
- сумму в ILS, способ оплаты и статус;
- относительный путь к счёту, квитанции или банковскому подтверждению;
- комментарий с номером документа, расхождениями или следующим действием.

## Статусы

- `подтверждено` — есть документ либо прямое подтверждение пользователя;
- `требует проверки` — не хватает квитанции, подтверждения получателя или
  другого важного документа;
- `отменено` — запись оставлена для истории, но не включается в итог.

## Отчёты

PDF-отчёты для отправки жильцам хранятся в `finance/reports/` и именуются
`expenses-YYYY-MM-he.pdf`. В них включать только операции со статусом
`подтверждено` за соответствующий месяц. Внешний вид и обязательные элементы
отчёта определяет `finance/reports/README.md`; эталон — отчёт за июнь 2026.
