# Финансы

## Реестры

- `payments.xlsx` — начисления, оплаты, задолженности и переплаты жильцов.
- `payments.md` — правила ведения взносов жильцов за домовой комитет
  (`מס ועד בית`).
- `apartments/` — карточки платежей по каждой квартире.
- `expenses/` — расходы домового комитета по месяцам в Markdown.
- `expenses/README.md` — контракт учёта расходов и правила отчётов.
- `reimbursements.md` — личные расходы к возмещению со счёта ועד הבית.
- `bank-account.md` — отдельная справка на иврите с текущими реквизитами
  счёта ועד הבית и ссылкой на источник.

Расходы записываются в `expenses/YYYY-MM.md`: одна строка таблицы описывает
одну операцию. Не удаляйте старые записи: корректировки добавляются отдельно
с пояснением.

Описания расходов заполняются на русском языке. В месячном Markdown-реестре
есть отдельная колонка `תיאור בעברית` с кратким описанием на иврите.

Статусы:

- `подтверждено` — есть документ или прямое подтверждение пользователя;
- `требует проверки` — сведения ещё нужно сверить;
- `отменено` — запись сохранена для истории, но не участвует в итогах.

Подтверждающие документы хранятся в `documents/invoices/` и
`documents/receipts/`. В реестре указывается относительный путь к файлу.

Подтверждения оплат жильцов за домовой комитет хранить отдельно в
`documents/payments/` и ссылаться на них из `payments.xlsx`.

Если расход оплатил пользователь личной картой или со своего счёта, он
дополнительно вносится в `reimbursements.md`. Там можно объединить несколько
расходов в одну будущую компенсацию, но сам возврат отмечается только после
отдельного подтверждения банковской операции.

Карточки квартир лежат в `finance/apartments/`. При каждом платеже
обновлять и карточку квартиры, и `payments.xlsx`, затем сверять суммы,
период, статус и документ.

Скриншоты и документы с банковскими реквизитами хранить отдельно в
`documents/bank-account/`. Перед отправкой реквизитов наружу или любым
банковским действием нужно получить явное подтверждение пользователя.

Пустой XLSX-шаблон нужен только для оплат жильцов и создаётся командой:

```sh
python3 scripts/create_finance_templates.py
```

По умолчанию команда не перезаписывает существующие реестры. Параметр
`--force` можно использовать только после отдельной резервной копии и
подтверждения.
