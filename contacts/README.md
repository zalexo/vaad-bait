# Контакты и организации

Этот раздел — маленькая CRM домового комитета.

## Файлы

- `contacts.xlsx` — люди: телефоны, роли, источник контакта, разрешённый
  способ связи и заметки.
- `organizations.xlsx` — дома, другие ועד בית, подрядчики, муниципальные
  отделы и другие организации.

## Правила

- `contacts.xlsx` хранит людей, а `organizations.xlsx` хранит дома и
  организации. Не смешивать человека и дом в одной сущности.
- У каждого контакта должен быть источник: от кого получен телефон,
  из какого документа или из какого кейса.
- Не переносить сюда собственников и жильцов из `owners.xlsx` и
  `residents.xlsx` без причины. Для них источники истины уже существуют.
- Если контакт связан с кейсом, указывать ID кейса в комментарии.
- Перед отправкой сообщения контакту нужно получить подтверждение
  пользователя.
- Не хранить лишние персональные данные: только то, что нужно для работы
  домового комитета.

Пустые шаблоны можно восстановить командой:

```sh
python3 scripts/create_crm_templates.py
```

Команда не перезаписывает существующие таблицы.
