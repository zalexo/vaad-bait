# Предложения жильцов

Здесь фиксируются идеи жильцов до того, как домовой комитет решит их
прорабатывать, отклонить или принять.

## Реестр

Все предложения ведутся в `proposals.md`. У записи должны быть ID, дата,
краткое описание, источник, статус и следующий шаг.

## Статусы

- `new` — идея записана, решения о ней нет.
- `reviewing` — собираем варианты, стоимость или мнение жильцов.
- `accepted` — принято решение реализовать; создать связанный кейс.
- `rejected` — решили не реализовывать; указать причину.
- `implemented` — работа завершена; указать связанный кейс и решение.

Не создавать кейс только ради записи идеи. Кейс открывается, когда нужно
вести работу до результата: назначить ответственного, получить сметы,
обсудить, заказать или выполнить действие.
